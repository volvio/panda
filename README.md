сторінка реєстрації url + email
http://localhost/olx/subscribe

для розгортання проекту використовується docker
образи налаштовані на laravel 12 php 8.4

Для розгортання проекту виконати команди

1.Встановити залежності Composer

composer install

2. Запустити контейнери Docker через Sail

./vendor/bin/sail up -d

3. Згенерувати ключ програми

./vendor/bin/sail artisan key:generate

4. Запустити міграції та сидери

./vendor/bin/sail artisan migrate --seed

5. Зібрати фронтенд (CSS/JS)

./vendor/bin/sail npm install

./vendor/bin/sail npm run dev

6. (Опціонально) Запустити тести

./vendor/bin/sail artisan test


команди
Оновити актуальні ціни

./vendor/bin/sail artisan olx:check-prices

Надіслати листа користувачам інформацію про оновлення ціни

./vendor/bin/sail artisan olx:send-price-updates

Загальна логіка роботи

1 . При реєстрації url та email за вказаним url виконується парсинг сторінки та отримуємо ID пропозиції (сервіс OlxService). Зберігаємо url та ID в базу даних

2. Через API отримуємо початкову ціну пропозиції та зберігаємо до бази даних сервіс OlxApiService

3. Збережемо email для розсилки користувачеві

Далі раз на 30 хвилин перевіряється зміна ціни через підготовлену команду olx:check-prices (використовується сервіс OlxApiService).
Для всіх змін ціни в таблиці з'являється новий запис з ціною і ставиться прапорець для цього url ціна змінилася

На наступному кроці раз на 30 хвилин виконується відправка листів по URL, де ціна змінилася по email адресам прив'язаним до цього URL; Наприкінці скидається прапор ціна змінилася у url

Для повного запуску на сервері потрібно прописати файл cron
* * * * * cd /path-to-your-laravel-project && php artisan schedule:run >> /dev/null 2>&1
На стадії тестування краще скористатися консольними командами.
